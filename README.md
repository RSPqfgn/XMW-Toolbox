# XMW Toolbox

为 [小码王](https://world.xiaomawang.com) 定制的 [Tampermonkey](https://www.tampermonkey.net/) 用户脚本：自动任务接管每日重复操作，界面定制清理红点与杂乱元素。基于 [XMWplus](https://github.com/RSPqfgn/XMWplus) 重构而来，两分钟装好即用。

## 它替你做什么

- **自动任务**：在面板中勾选任务（每日签到 / 点赞 / 收藏 / 每周作品发布），在独立的标签页内自动完成并领取奖励；执行时会提示进度，可随时中止。全程在**单个标签页内跨页面推进**，无需逐页手动操作。
- **后台自动**：自动领取奖励、自动签到、自动展开评论 / 子回复（按钮进入屏幕后才触发，避免卡顿）、自动点击「查看更多」。
- **一键查询**：按 ID 查询用户 / 作品 / 工作室信息，支持快速跳转。
- **界面定制**：消息 / 动态 / 任务中心免打扰、移除头像框与魔力测评、自适应文本框、作品菜单「编辑信息」入口。
- **Markdown**：评论与作品简介支持 Markdown 渲染显示；为多行文本框添加 Markdown 格式工具栏与预览。
- **悬浮球**：可拖动的工具入口，位置自动记忆。

## 安装

1. 先安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展。
2. 打开下方链接，Tampermonkey 会自动弹出安装确认，点击「安装」即可：

   [安装 XMW Toolbox.user.js](https://raw.githubusercontent.com/RSPqfgn/XMW-Toolbox/main/XMW%20Toolbox.user.js)

   （也可以手动新建脚本，粘贴 [`XMW Toolbox.user.js`](./XMW%20Toolbox.user.js) 的全部内容后保存。）
3. 刷新任意小码王页面，右下角会出现悬浮球，即安装成功。

## 快速上手

点击屏幕右侧的**悬浮球**即可进入工具：

- **自动任务**：勾选要执行的任务 → 点「开始」，脚本会自动打开任务标签页并在其中完成签到 / 点赞 / 收藏 / 发布，最后领取奖励并汇报结果。
- **查询**：输入用户 / 作品 / 工作室 ID，一键查询并跳转。
- **设置**：一键配置 XMW Toolbox 的各种功能。

> 若自动任务使用的弹窗被浏览器拦截，请在地址栏允许本站弹出窗口后重试。

## 更新日志

### v2.1.0（2026-08-30）

- **新增 Markdown 渲染**：评论与作品简介支持 Markdown 显示，自动识别链接。
- **新增 Markdown 编辑器**：为多行文本框添加格式工具栏与预览切换。
- **改进 自动展开评论 / 子回复**：「更多评论」「展开更多回复」按钮进入屏幕可见范围后才自动点击，避免连锁展开导致页面卡顿。
- **改进 设置面板**：恢复了原 XMWplus 中设置后关闭面板询问是否立即刷新页面的功能；「自动任务」分组更名为「自动化」；「关于」页新增大标题与作者 GitHub 主页链接，移除推荐链接。
- **调整**：自适应文本框不再对单行输入框做宽度适配，仅保留文本域高度自适应。

### v2.0.0

- 添加了自动任务功能。
